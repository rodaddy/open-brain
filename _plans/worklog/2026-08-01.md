## TRIED-AND-LEARNED

- **[RUNNING] Headless Sol/Terra dispatches can orphan their own workers.** A
  headless session can start background workers and exit before collecting their
  results. Dispatch prompts now begin with explicit requirements to work
  sequentially in-session and print the complete report before exit.
- **[RUNNING] The Claudex proxy was unavailable at the first Terra dispatch.**
  The command exited `1` with `proxy unavailable`; `claudex proxy start`
  restored dispatch without another login.
- **[RUNNING] Passing the whole observation env into new hooks silently produced
  zero capture.** Config validation rejected seven undeclared `OPENBRAIN_*`
  variables, then fail-open hook behavior swallowed the error. The shipped fix is
  the `openbrain-hook-env` wrapper: it starts with `env -i` and passes only
  `OPENBRAIN_BASE_URL` and `OPENBRAIN_TOKEN`.
- **[RUNNING] Headless `claude -p` is not a valid capture proof.** Those turns
  carry `promptSource:sdk`, which capture excludes by design; a capture test must
  provide an interactively shaped prompt source.
- **[RUNNING] A session that spans its own cutover retains its original capture
  path.** Removing the advertised path during that session makes it unavailable,
  while the archived `_archive` path remains functional for the session's
  remainder.
