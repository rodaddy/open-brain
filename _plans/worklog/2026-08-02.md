## TRIED-AND-LEARNED

- **[RUNNING] A hanging local `/health` was PostgreSQL checkpoint pressure, not an
  Open Brain outage.** A neighbouring project's per-test `CREATE/DROP DATABASE
  WITH FORCE` churn on the deliberately shared PostgreSQL 18 instance produced
  72 forced checkpoints in 3 minutes; `pg_stat_checkpointer.num_requested` was
  21,212 against `num_timed` 1,057. `SELECT 1` exceeded the pool's five-second
  window, then the service recovered in place.
- **[RUNNING] Something concurrent can flip the main checkout to
  `core.bare=true`.** The actor is UNATTRIBUTED as of 2026-08-02. It was observed
  twice within about 30 minutes and made the deploy script fail at its dirty-tree
  guard with `fatal: this operation must be run in a work tree`. Resetting local
  config to `core.bare=false` and re-proving `rev-parse --is-inside-work-tree`
  restored the checkout; deploy workers now re-assert it.
- **[RUNNING] A restart warning followed by green health can be a false deploy
  receipt.** `launchctl kickstart` requires `gui/$UID/<label>`; the bare label
  fails with `Unrecognized target specifier`. At `2026-08-02T04:12:18Z`, the
  deploy script warned and then checked the old process still serving. A fix PR
  is open on `fix/deploy-runbook-and-kickstart`.
- **[RUNNING] A provider capture must be checked in `ob_session_events`, not
  `ob_raw_turns`.** The live smoke returned a saved/durable receipt, raw-turn
  delta 0, and durable event `2496e009-a2a3-48af-9aa5-6ea1996c9c1a`.
  Raw-turn counts prove only raw-turn ingestion.
- **[RUNNING] Codex/Terra one-shots can exit 0 with deferral prose after partial
  or no work.** This happened twice on 2026-08-01/02. Completion must be checked
  against GitHub or the filesystem, and the execution contract must require the
  artifact URL in the worker's own output.
- **[MERGED — feature branch] `AskUserQuestion` had an impossible lookup subject.**
  `mutationSubject()` used `file_path`, which is empty for questions, so no
  lookup could match. Commit `bfb9389` on
  `audit/router-dedupe-matrix-2026-08-02` changes the subject to the question
  text.
