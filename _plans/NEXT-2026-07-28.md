## Traps that cost time tonight

- **`aqmd search "<word>"` takes 0.1s and beats reading files.** Skipping it
  cost an hour rediscovering #192/#247 and produced three wrong proposals.
  `.claude/hooks/design-lookup-gate.ts` now blocks mutating tools without a
  lookup on *that subject*; an unrelated lookup no longer counts.
- **`.env` is missing 25 keys that `.env.example` documents.** The embedding
  block was among them, so `EMBEDDING_MODEL` defaulted to `gemini-embedding-001`
  and 1,000/1,000 embed calls failed silently. Added; the rest are still absent.
- **A declared-but-unpopulated column is worse than a missing one.** It
  typechecks, satisfies every constraint, and returns an empty result set that
  reads as "no data" instead of "broken link". 044 adds a CHECK so the database
  refuses the half-written form.
